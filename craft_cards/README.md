# Craft Cards

Craft cards are the only research-derived artifacts the writer product should see directly.

Each card should be small, testable, and writing-focused.

## Rules

- one idea per card
- grounded in at least one source
- written as actionable guidance
- tied to one or two scoring dimensions
- easy to test in one experiment

## Lifecycle

1. drafted from research
2. approved for testing
3. tested in the inner loop
4. promoted or retired
