# Benchmark Lane

Hidden real-book benchmark lane for the writing system. Phase 0-1 implemented.

## Scope

- Phase 0: offline corpus prep and benchmark artifact layout
- Phase 1: one-book validation spike against Dunsany (5 chapters)

## Non-Goals

- No writer prompt should ever see raw source-book text from `source_canon/`
- No benchmark output should be copied into `best/`
- No change here should alter the default synthetic evaluation loop

## Directory Layout

- `source_canon/`: hidden source-side canon and extracted facts (generated by remix_compiler)
- `remixed_canon/`: writer-facing remixed continuity artifacts (generated by remix_compiler)
- `chapter_specs/`: per-chapter objective summaries for the writer (generated by remix_compiler)
- `spike_inputs/`: source chapter files extracted by chapter_splitter (5 Dunsany chapters)
- `results/`: benchmark run results (generated by benchmark_lane)

## Code

- `chapter_splitter.py` -- parses Gutenberg source text into individual chapter files
- `remix_compiler.py` -- transforms source chapters into blind remixed artifacts via local LLM
- `novelty_auditor.py` -- pure Python n-gram overlap and shared phrase detection
- `fidelity_checker.py` -- local LLM check that generated chapter follows the remixed spec
- `benchmark_lane.py` -- main driver tying the full pipeline together

## Usage

Step 1: Extract chapters (already done for Dunsany, 5 chapters in spike_inputs/):
```
python benchmark/chapter_splitter.py research/sources/gutenberg/the_king_of_elflands_daughter_pg61077.body.txt --chapters 5
```

Step 2: Compile remix artifacts (requires Ollama running with qwen3.5):
```
python benchmark/benchmark_lane.py --compile-only
```

Step 3: Run benchmark (without frontier pairwise):
```
python benchmark/benchmark_lane.py --all
```

Step 4: Run with frontier pairwise comparison (requires ANTHROPIC_API_KEY):
```
python benchmark/benchmark_lane.py --all --pass2
```

## Phase 1 Exit Criteria

- At least 1 chapter win (NEW_BETTER) in pairwise vs source
- Zero copying failures (novelty audit)
- Stable judge behavior on rerun for winning chapters
- If zero wins or unusable judge noise, log the failure and do not advance to Phase 2

## Phase 2-3 (deferred)

Full universe packs and global promotion gating are deferred to follow-on proposals, gated by Phase 1 results.
